Projects

Capstone

Secure Geospatial Data Engineering Architecture

Al Akhawayn University with ANCFCC, 2026

A modern, containerized data pipeline built as a standalone alternative to ANCFCC's aging land-registration platform, adding the geospatial visualization and analytics the old system lacked, all on structurally faithful synthetic data, since real land records are confidential.

  • Event-driven ingestion (a webhook with a five-minute polling fallback) feeds a MinIO data lake, so every raw file is kept and any run can be replayed.
  • An Apache Airflow DAG detects, pre-validates, loads, and archives each parcel; seven declarative rules run on every file, each failure stored with a stable code for analytics.
  • A single SQL Server warehouse holds business data and native geometry (Morocco Lambert, SRID 26191) in one transaction, with no separate spatial database to drift out of sync.
  • An interactive Leaflet map renders the full zone, sous-zone, douar and parcel hierarchy, with live containment and overlap checks while boundaries are drawn.
  • Security throughout: uploads quarantined and scanned with ClamAV, bcrypt with a NIST length policy, breach screening via HaveIBeenPwned k-anonymity, rotating JWT refresh tokens, brute-force lockout.
  • Deployed on an isolated Azure VM: sixteen services brought up with a single docker compose command, behind a fully bilingual French and Arabic interface.
